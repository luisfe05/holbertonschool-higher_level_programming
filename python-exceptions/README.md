# Python - Exceptions

## Files

| File / Task Name | Description |
| :--- | :--- |
| `0-safe_print_list.py` | Prints x elements of a list safely using try/except. |
| `1-safe_print_integer.py` | Prints an integer with `"{:d}".format()`. |
| `2-safe_print_list_integers.py` | Prints the first x elements of a list and only integers. |
| `3-safe_print_division.py` | Divides 2 integers and prints the result inside a finally section. |
| `4-list_division.py` | Divides element by element 2 lists with error handling. |
| `5-raise_exception.py` | Raises a type exception (`TypeError`). |
| `6-raise_exception_msg.py` | Raises a name exception (`NameError`) with a custom message. |
