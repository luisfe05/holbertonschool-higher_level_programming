# Python - Object-Relational Mapping (ORM)

## Description
This project covers connecting Python to MySQL databases using `MySQLdb` (raw SQL queries) and `SQLAlchemy` (Object Relational Mapper).

## Tasks

| Task | Description | Source Code / File |
| --- | --- | --- |
| **0. Get all states** | Script that lists all states from `hbtn_0e_0_usa` using `MySQLdb`. | [0-select_states.py](./0-select_states.py) |
| **1. Filter states** | Script that lists all states with a name starting with N (upper N). | [1-filter_states.py](./1-filter_states.py) |
| **2. Filter states by user input** | Script that displays state matching the argument using string `.format()`. | [2-my_filter_states.py](./2-my_filter_states.py) |
