# SQL - Introduction

## Description
This directory contains tasks for exploring relational database management system (RDBMS) concepts, installing and configuring MySQL Server 8.0, interacting with databases using SQL commands (DDL and DML), executing queries, using functions and subqueries, and running SQL scripts using the command-line interface.

## Tasks

| Task | Description | Source Code / File |
| --- | --- | --- |
| **0. List databases** | Script that lists all databases of the MySQL server. | [0-list_databases.sql](./0-list_databases.sql) |
| **1. Create a database** | Script that creates the database `hbtn_0c_0` if it does not already exist. | [1-create_database_if_missing.sql](./1-create_database_if_missing.sql) |
