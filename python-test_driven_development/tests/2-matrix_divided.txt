=============================
How to Use 2-matrix_divided.py
=============================

This module provides the ``matrix_divided(matrix, div)`` function.

Usage
=====

Importing the function:
    >>> matrix_divided = __import__('2-matrix_divided').matrix_divided

Normal operation:
    >>> matrix = [[1, 2, 3], [4, 5, 6]]
    >>> matrix_divided(matrix, 3)
    [[0.33, 0.67, 1.0], [1.33, 1.67, 2.0]]

Verify original matrix is unmodified:
    >>> matrix
    [[1, 2, 3], [4, 5, 6]]

Dividing floats and negative numbers:
    >>> matrix_divided([[1.5, -2.5], [3.0, 4.0]], 2)
    [[0.75, -1.25], [1.5, 2.0]]
