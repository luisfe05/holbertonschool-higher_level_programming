===========================
How to Use 0-add_integer.py
===========================

This module provides the function ``add_integer(a, b=98)``.

Usage
=====

Importing the function:
    >>> add_integer = __import__('0-add_integer').add_integer

Passing two integers:
    >>> add_integer(1, 2)
    3

Passing negative numbers:
    >>> add_integer(100, -2)
    98

Passing only one argument (b defaults to 98):
    >>> add_integer(2)
    100

Passing floating point numbers:
    >>> add_integer(100.3, -2)
    98

Passing floats for both arguments:
    >>> add_integer(2.6, 3.8)
    5
