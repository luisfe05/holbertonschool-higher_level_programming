# JavaScript - DOM Manipulation

## Description
This project covers selecting and manipulating HTML elements in the browser with JavaScript: querying the DOM, updating element styles and content, modifying the DOM tree, listening to DOM/user events, and making network requests with `XmlHTTPRequest` and the Fetch API. Scripts are run in Chrome (57.0+) against provided HTML pages, and code is `semistandard` compliant.

## Tasks

| Task | Description | File |
| :--- | :--- | :--- |
| **0. Color Me** | Write a script that selects the `header` element with `document.querySelector` and sets its text color to red (`#FF0000`). | `0-script.js` |
| **1. Click and turn red** | Write a script that turns the `header` text red (`#FF0000`) when the element with id `red_header` is clicked. | `1-script.js` |
| **2. Add `.red` class** | Write a script that adds the `red` class to the `header` element when the element with id `red_header` is clicked. | `2-script.js` |
| **3. Toggle classes** | Write a script that toggles the `header` element's class between `red` and `green` (never both, never empty) when the element with id `toggle_header` is clicked. | `3-script.js` |
