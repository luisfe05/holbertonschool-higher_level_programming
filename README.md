# Holberton School - Higher Level Programming

## 📝 Overview
This repository contains projects and assignments completed as part of the **Higher Level Programming** track at **Holberton School**. It covers fundamental to advanced concepts in Python, Object-Oriented Programming (OOP), Relational Databases (SQL), Object-Relational Mapping (ORM), API design, and testing.

---

## 📂 Repository Structure

| Directory | Description |
| :--- | :--- |
| **`python-hello_world`** | Introduction to Python, basic syntax, and printing. |
| **`python-if_else_loops_functions`** | Control flow statements, conditional execution, loops, and custom functions. |
| **`python-import_modules`** | Importing built-in and custom modules, passing command-line arguments. |
| **`python-data_structures`** | Working with sequence types: Lists and Tuples. |
| **`python-more_data_structures`** | Key-value pairs and unique collections: Sets and Dictionaries, plus Lambda functions. |
| **`python-exceptions`** | Error handling using `try`, `except`, `raise`, and `finally`. |
| **`python-classes`** | Object-Oriented Programming basics: Attributes, methods, instantiation, and encapsulation. |
| **`python-more_classes`** | Advanced OOP concepts: Class methods, static methods, string representations (`__str__`, `__repr__`). |
| **`python-test_driven_development`** | Writing unit tests using `doctest` and `unittest` modules. |
| **`python-inheritance`** | Inheritance, superclasses, subclasses, overriding methods, and built-in type checking. |
| **`python-abc`** | Abstract Base Classes, interfaces, and polymorphism in Python. |
| **`python-input_output`** | Reading and writing files, using file streams, and working with JSON format. |
| **`python-serialization`** | Object serialization and deserialization techniques (JSON, Pickle, CSV, XML). |
| **`SQL_introduction`** | Relational Database Management Systems basics: Databases, tables, CRUD operations in MySQL. |
| **`SQL_more_queries`** | Advanced SQL: Joins, subqueries, constraints, foreign keys, and user permissions. |
| **`python-object_relational_mapping`** | Connecting Python to MySQL using `MySQLdb` and `SQLAlchemy` ORM. |
| **`restful-api`** | Fundamentals of building RESTful Web APIs, HTTP methods, status codes, and security. |
| **`javascript-warm_up`** | JavaScript scripting fundamentals: variables (`const`/`let`), data types, `console.log`, control flow, and functions. |
