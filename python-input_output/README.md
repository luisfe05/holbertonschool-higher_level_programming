# Python - Input/Output

## Description
This directory contains tasks for learning file handling, standard I/O, JSON serialization, and deserialization in Python.

## Files
| File / Task Name | Description |
| ------ | ------ |
| 0-read_file.py | Reads a UTF-8 text file and prints its content to stdout. |
| 1-write_file.py | Writes a string to a UTF-8 text file and returns the number of characters written. |
| 2-append_write.py | Appends a string to the end of a UTF-8 text file and returns the number of characters added. |
| 3-to_json_string.py | Returns the JSON representation of an object as a string. |
| 4-from_json_string.py | Returns a Python object represented by a JSON string. |
